# Arena Ball Brawl

Open `index.html` in a browser to play.

The menu is a single `Play` button. When pressed, two random fighters are picked from the four-ball roster and a short arena match begins.

Controls:
- No controls needed.
- The balls auto-bounce, orbit weapons, and trigger abilities.
- Each fighter has a different ability:
  - Comet: Dash
  - Frost: Freeze
  - Blaze: Pulse
  - Thorn: Shield

The match ends when one fighter's health reaches zero, and the menu returns with a `Play Again` button.

To run locally:
1. Open `index.html` directly in your browser, or
2. serve the folder with a tiny local server using `python -m http.server` and visit `http://localhost:8000`.
